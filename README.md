# Verify Public Spending Citations

This Python script simulates the verification of public spending figures by checking for missing sources, inconsistent amounts, and overall discrepancies in reported versus actual spending. It demonstrates how to programmatically identify potential citation issues in financial data.

## Language

`python`

## How to Run

Save the code as `verify_spending.py` and run it from your terminal using: `python verify_spending.py`
